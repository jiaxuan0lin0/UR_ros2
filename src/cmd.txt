新方案启动顺序：direct RTDE arm + /tmp/ttyUR gripper + ROS2 recorder

注意：高性能 direct RTDE 采集方案里不要再启动 ur_control.launch.py 和 MoveIt Servo。
机械臂由 src/teleop/teleop.py 直接通过 RTDE 控制；ROS2 只负责相机和 recorder。


终端 0：编译并 source

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/.venv/bin/activate
colcon build --symlink-install --packages-select recorder
source /home/ustc/UR/install/setup.bash


终端 1：启动 XRoboToolkit PC Service

# 只需要启动一次。它是 XR 设备和 xrobotoolkit_sdk 之间的桥。
/opt/apps/roboticsservice/runService.sh

# 检查是否已经在跑：
pgrep -af RoboticsServiceProcess


终端 2：启动机械臂本体（上电、释放刹车）

# 重要：示教器需要切到 Remote Control。
# 这一步不是启动 ROS driver，而是通过 UR Dashboard Server 让机器人进入可 RTDE 控制状态。
cd /home/ustc/UR
python3 src/teleop/start_ur.py --robot-ip 192.168.1.102

# 如果 safetymode 是 PROTECTIVE_STOP，先确认现场安全，再单独执行：
# python3 src/teleop/start_ur.py \
#   --robot-ip 192.168.1.102 \
#   --unlock-protective-stop


终端 3：启动 /tmp/ttyUR tool communication

# 需要机器人端 ToolComm Forwarder URCap 已经运行，默认端口 54321。
python3 /opt/ros/jazzy/lib/ur_client_library/tool_communication.py \
  192.168.1.102 \
  --device-name /tmp/ttyUR

# 看到 /tmp/ttyUR 后再开 teleop：
ls -l /tmp/ttyUR


终端 4：启动高性能 teleop

cd /home/ustc/UR
source /home/ustc/anaconda3/etc/profile.d/conda.sh
conda activate XRobo
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/install/setup.bash

# 确认 xrobotoolkit_sdk 来自 XRobo 环境：
python -c "import xrobotoolkit_sdk as xrt; print(xrt.__file__)"

python3 src/teleop/teleop.py \
  --robot-ip 192.168.1.102 \
  --control-mode servo_j \
  --rate-hz 300 \
  --max-velocity 0.15 \
  --max-acceleration 0.15 \
  --lookahead-time 0.12 \
  --servo-gain 300 \
  --scale-factor 0.8 \
  --rotation-scale 0.8 \
  --max-step-translation 0.002 \
  --max-step-rotation 0.005 \
  --max-joint-step 0.003 \
  --gripper-port /tmp/ttyUR \
  --state-file /tmp/ur_teleop_state.json \
  --enable-recorder-control \
  --return-home-max-joint-step 0.003 \
  --return-home-timeout-sec 30

# 操作：
#   按住右手 grip 才移动机械臂。
#   右手 trigger 控制夹爪。
#   右摇杆按下 emergency stop。
#   A: start recording
#   B: return home, record that return motion, then stop current episode
#   X: save stopped episode
#   Y: discard stopped episode


终端 5：启动 recorder

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/.venv/bin/activate
source /home/ustc/UR/install/setup.bash

ros2 launch recorder record.launch.py \
  robot_ip:=192.168.1.102 \
  dataset_root:=/home/ustc/UR/dataset \
  teleop_state_file:=/tmp/ur_teleop_state.json \
  python_executable:=/home/ustc/UR/.venv/bin/python3


终端 6：控制采集（可选）

如果终端 4 的 teleop 已经加了 --enable-recorder-control，可以直接用手柄控制：

#   A: start recording
#   B: return home, record that return motion, then stop current episode
#   X: save stopped episode
#   Y: discard stopped episode

下面这个键盘节点只是备用控制方式。

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/.venv/bin/activate
source /home/ustc/UR/install/setup.bash

ros2 run recorder keyboard_control

# 按键：
#   r: start recording
#   c: stop current episode
#   s: save stopped episode
#   q: discard stopped episode
#   x: exit keyboard control


不用键盘节点时，也可以直接调 service：

ros2 service call /recorder/start std_srvs/srv/Trigger {}
ros2 service call /recorder/stop std_srvs/srv/Trigger {}
ros2 service call /recorder/save std_srvs/srv/Trigger {}
ros2 service call /recorder/discard std_srvs/srv/Trigger {}


============================================================
备用方案：传统 ROS2 controllers 链路
============================================================

这个方案用于需要 ROS2 action / controller / MoveIt 集成的时候。
它和上面的 direct RTDE teleop 不能同时控制同一台机械臂。

注意：
- 走这个方案时，不要启动 src/teleop/teleop.py。
- 不要单独运行 tool_communication.py，因为 ur_robot_driver 会通过
  use_tool_communication:=true 创建 /tmp/ttyUR。
- controllers/ur_joint_control 默认需要
  /scaled_joint_trajectory_controller/follow_joint_trajectory。


终端 A：编译 controllers

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select controllers controllers_msgs
source /home/ustc/UR/install/setup.bash


终端 B：启动 UR ROS2 driver + /tmp/ttyUR + scaled_joint_trajectory_controller

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/install/setup.bash

ros2 launch ur_robot_driver ur_control.launch.py \
  ur_type:=ur7e \
  robot_ip:=192.168.1.102 \
  launch_rviz:=false \
  headless_mode:=true \
  use_tool_communication:=true \
  tool_device_name:=/tmp/ttyUR \
  tool_baud_rate:=115200 \
  tool_parity:=0 \
  tool_stop_bits:=1 \
  tool_rx_idle_chars:=1.5 \
  tool_tx_idle_chars:=3.5 \
  tool_voltage:=24 \
  initial_joint_controller:=scaled_joint_trajectory_controller


终端 C：启动本仓库 controllers facade

cd /home/ustc/UR
source /opt/ros/jazzy/setup.bash
source /home/ustc/UR/install/setup.bash

ros2 launch controllers ur_joint_control.launch.py


检查：

ros2 action list | grep trajectory
ros2 topic echo /joint_states --once
ros2 topic echo /gripper_joint_states --once

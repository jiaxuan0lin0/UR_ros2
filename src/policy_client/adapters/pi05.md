# PI0.5 Adapter 接入说明

本文档定义 PI0.5 类模型接入 `policy_client` 时应满足的机器人侧约定。PI0.5 server 的真实 endpoint、鉴权、payload 字段和模型侧 RTC prefix guidance 需要以实际 server contract 为准。

## 1. 接入目标

| 项目 | 约定 |
| --- | --- |
| 机器人侧 action | 7D `[q1, q2, q3, q4, q5, q6, gripper]` |
| action 语义 | absolute joint target + gripper command target |
| action knot 频率 | 30 Hz |
| 执行频率 | 500 Hz RTDE `servoJ` |
| 部署侧 RTC | `rtc_control_enabled=true` |
| 模型侧 RTC | 由 PI0.5 server 实现 prefix guidance 或 inpainting |

## 2. 推荐 server contract

### `/health`

```bash
curl http://<HOST>:<PORT>/health
```

### `/reset`

```bash
curl -X POST http://<HOST>:<PORT>/reset
```

### `/act`

请求建议包含：

```json
{
  "instruction": "task text",
  "images": {
    "primary": "<adapter-defined image encoding>",
    "wrist": "<adapter-defined image encoding>"
  },
  "state": [0, 0, 0, 0, 0, 0, 0],
  "executed_actions": [
    [0, 0, 0, 0, 0, 0, 0]
  ],
  "rtc_prefix_actions": [
    [0, 0, 0, 0, 0, 0, 0]
  ]
}
```

响应建议包含：

```json
{
  "action": [0, 0, 0, 0, 0, 0, 0],
  "action_chunk": [
    [0, 0, 0, 0, 0, 0, 0]
  ],
  "history": {}
}
```

## 3. Adapter 文件

### 通用路径

```text
src/policy_client/policy_client/scripts/pi05.py
```

### 通用启动

```bash
ros2 launch policy_client policy_joint_abs_control.launch.py \
  policy_base_url:=http://<HOST>:<PORT> \
  policy_script:=pi05 \
  instruction:="<TASK_INSTRUCTION>" \
  rtc_control_enabled:=true \
  rtc_execution_horizon:=10 \
  rtc_transition_schedule:=exp
```

### 示例

```bash
ros2 launch policy_client policy_joint_abs_control.launch.py \
  policy_base_url:=http://127.0.0.1:8777 \
  policy_script:=pi05 \
  instruction:="perform the requested manipulation task" \
  rtc_control_enabled:=true \
  rtc_execution_horizon:=10 \
  rtc_transition_schedule:=exp
```

## 4. RTC 配置

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `rtc_control_enabled` | `true` | 启用机器人侧 chunk 过渡 |
| `rtc_execution_horizon` | `10` | 前缀过渡帧数 |
| `rtc_transition_schedule` | `exp` | 过渡曲线 |
| `rtc_exp_decay` | `4.0` | 指数衰减 |
| `async_policy` | `true` | 当前 chunk 执行时预取下一次推理 |
| `async_policy_prefetch_after_frames` | `8` | 开始预取的执行帧数 |

模型侧 PI0.5 RTC prefix guidance 与机器人侧 RTC 互补。模型侧用于生成更一致的新 chunk，机器人侧用于在真实执行时抑制新旧 chunk 边界跳变。

## 5. 实现检查表

| 检查项 | 要求 |
| --- | --- |
| `create_policy_client()` | 返回 `PolicyClient` 子类实例 |
| 图像编码 | 与 PI0.5 server contract 完全一致 |
| state 维度 | adapter 内转换为 server 需要的格式 |
| action 输出 | adapter 返回前转换回机器人侧 7D |
| chunk 频率 | 与 `joint_point_duration_sec=1/30` 对齐 |
| gripper 语义 | 输出控制目标，不输出下一帧 observation |
| reset | `/policy_control/reset_policy` 能清空 server 历史 |
